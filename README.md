# RomStation Cloud Android TV

**Status: Work in Progress**

This application is an Android implementation for the RomStation cloud gaming service, specifically optimized for Android TV devices like the Mi Box. It offloads the RomStation cloud gaming experience to native Android Java for better performance on TV hardware.

## Features
- Optimized for Android TV (Mi Box).
- Native Java implementation for RomStation cloud streaming.
- Gamepad support for cloud gaming sessions.
- Low-latency RTSP streaming via ExoPlayer.

## Usage
This app allows you to connect to RomStation cloud gaming sessions directly from your Android TV device.
